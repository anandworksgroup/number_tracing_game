# Google Play store listing

Draft copy and asset checklist for the Play Console (*Grow → Store presence → Main store listing*).
Rebuild the graphics with `npm run store-assets` after changing the app. It takes the
screenshots from the Flutter app.

## App details

**App name** (max 30 characters)

> 123 Trace & Count: Kids Math

**Short description** (max 80 characters)

> Learn to write numbers 0–20 with guided tracing, counting and balloon games.

**Full description** (max 4000 characters)

> Help your child learn to write and count numbers with 123 Trace & Count, a bright and friendly numbers game made for toddlers and preschoolers.
>
> TRACE NUMBERS 0 TO 20
> • Follow the green dot and the moving arrows to write each number the right way
> • A helping hand shows every stroke before your child begins
> • Numbered badges show stroke order for numbers like 4, 5 and 10–20
> • Pick a crayon colour and watch the number fill in with sparkles
> • Gentle feedback: going off the line never erases progress
>
> REWARDS THAT TEACH
> • Earn up to 3 stars for every number
> • Confetti and a counting reward: trace 4 and count four strawberries out loud
>
> TAP TO COUNT
> • Tap each object to hear it counted, then choose how many there are
>
> POP THE NUMBER BALLOONS
> • Listen for a number and pop the matching balloons
>
> MADE FOR LITTLE LEARNERS
> • Every number is spoken aloud
> • Big buttons and simple screens for small hands
> • Works offline, so it's great for car rides and flights
> • Progress is saved on the device; a parents area behind a grown-up question lets you reset it
> • No ads, no in-app purchases, no accounts and no personal data collected
>
> Made for children aged 2 to 5 who are learning numbers, counting and early handwriting.

Store text follows Play's metadata policy: no emoji in the title or headings, no
promotional claims ("best", "#1", "free", "perfect"), no references to other apps, and every
feature described is in the app.

## Play Console answers and policy checklist

Checked against the Google Play Developer Program Policies, including the Families Policy
for apps that target children.

| Area | Status |
| --- | --- |
| Target audience | Select only **Ages 5 and under**. The app is then reviewed under the Families Policy. |
| Ads | None. Declare **No ads**. |
| In-app purchases | None. |
| Data safety | Answer **No** to "Does your app collect or share any of the required user data types?" There are no accounts, so no account deletion is needed. |
| Permissions | The release build requests none. `INTERNET` exists only in debug/profile builds. |
| Third-party SDKs | `flutter_tts` (on-device text-to-speech), `audioplayers` (bundled sounds), `shared_preferences` (local storage). None collect data or show ads. |
| Parental gate | Parent-only actions (privacy info, reset) sit behind a multiplication question. No links out of the app. |
| Privacy policy | `privacy.html`. Must be hosted at a public URL and entered in the Play Console. |
| Target API level | Targets Android 16 (API 36), which meets Play's current requirement. |
| 64-bit and 16 KB pages | Flutter release builds include 64-bit code and support 16 KB memory pages. The plugins add no native libraries. |
| Content rating | Complete the IARC questionnaire: no violence, fear, language, gambling, user interaction or data sharing, so expect *Everyone* / *PEGI 3*. |
| Store graphics | Original artwork. Screenshots are taken from the Flutter app itself (the build you upload), on phone, 7-inch and 10-inch tablet screen sizes. |
| Intellectual property | Original name, art, sounds and code, with no references to other apps in the store listing. The bundled Baloo 2 font is under the SIL Open Font License. |
